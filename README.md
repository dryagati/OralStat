# OralStat

Wireless electrochemical sensing platform for real-time detection of biomarkers.
Developed at the University of Pennsylvania.

## Features
- Bluetooth-enabled mini-potentiostat
- Wireless electrochemical sensing
- Real-time SWV measurements
- Multiplexed pathogen metabolite detection
- Portable oral-swab platform
